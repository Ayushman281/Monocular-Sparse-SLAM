# AWS deployment

The maintained, step-by-step AWS deployment guide is [aws/README.md](../aws/README.md).

It covers the EC2/Docker architecture, cost and sizing checks, security-group rules, Docker installation, source transfer, configuration, frontend/backend startup, health verification, benchmarking, HTTPS, operations, troubleshooting, and the actual-deployment evidence table.

No AWS URL or measured AWS performance is claimed until that guide's deployment record is completed on a real host.
